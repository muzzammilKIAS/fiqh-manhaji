# موسوعة الفقه المنهجي – قسم العبادات

تطبيق ويب عربي (ملف واحد) لعرض فقه العبادات على مذهب الإمام الشافعي من قاعدة بيانات،
مع هيكل العناوين (باب ← موضوع ← عنوان فرعي)، وملخصات وتشجير، واستوديو شرائح للدروس (PdP)
بخمسة أنماط، وبطاقات مراجعة.

> **نص الكتاب غير مضمَّن في هذا المستودع** (حقوق الطبع). يُولَّد محلياً بـ
> `python3 scripts/build_from_shamela.py` من نسخة الشاملة المرخّصة، أو يُستورد ملف JSON من صفحة
> «إدارة البيانات» داخل التطبيق (يُحفظ في المتصفح فقط).

```bash
npm install      # لأدوات الاختبار فقط
npm start        # http://localhost:8080
npm test
```

اقرأ `CLAUDE.md` لقواعد المحتوى والبنية قبل التعديل.
